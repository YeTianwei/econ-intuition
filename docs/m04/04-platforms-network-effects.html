平台、网络效应与零边际成本

Platforms, network effects and zero marginal cost

人多不只是让成本摊得更薄，也可能让一项服务变得更有用。但“越多人用越有用”不等于每个市场都只剩一家，更不等于用户最多的平台可以永远随意收费。

约 23 分钟 · 1 个可调节的图 · 5 道自测题 · 8 张闪卡

前置：成本与规模经济、竞争与垄断、寡头与反垄断。沿用效率与分配的区分，把用户之间的反馈也纳入分析。

从一条新闻开始

平台、补贴与抽成变化均为虚构，没有暗指任何真实公司的经营记录。我们不预设补贴一定能换来垄断，也不预设后来收费必然不合理。先把用户获得的价值、平台付出的成本和退出难度拆开。

  1. 平台为什么可能愿意先补贴一方，甚至让这边的价格低于服务成本？
  2. 早期用户更多的一家，是否一定会赢得整个市场？
  3. 平台的软件复制很便宜，后来提高抽成是否就必然没有成本依据，用户又为何不立即离开？

多一个用户，会不会让别人也更想加入

网络效应 (network effect) 指一项产品对某个使用者的价值，随着其他参与者的数量或组成而改变。这里主要讨论正向反馈：人更多，匹配或交流机会更多，其他人更愿意加入。它不是互联网产品专有的标签，也不是所有“用户增长”的同义词。

直接网络效应 (direct network effect) 来自同一侧用户彼此连接。假想的通信工具里，更多朋友加入，你能直接联系的人就更多；即使公司生产每份软件的成本完全不变，你也可能更愿意使用它。

间接网络效应 (indirect network effect) 则通过另一侧参与者起作用。一个假想交易平台上，买家增加使商家更愿入驻，更多合适商家又吸引买家。对某个买家而言，其他买家未必是直接价值来源，连接两侧的反馈才是关键。

“更多”也可能带来拥挤、广告干扰或更强的同侧竞争。外卖平台上商家更多可以增加消费者选择，但对某一家商家而言，更多同行也会争夺同一批订单。判断网络效应要说明哪一侧、通过哪个机制、对谁的价值增加，不能把所有人数变化都视为利好。

类比

组织读书会时，空房间再漂亮，也不一定让你愿意每周来。朋友加入后，可以讨论的人多了，你更想参加，这是网络效应；人数多了，每人分摊的场地租金少了，这是成本摊薄。两件事能一起发生，但不是同一件事。

网络效应与规模经济，不在同一本账上

规模经济 (economies of scale) 看长期单位生产成本是否随规模下降；网络效应看其他参与者是否提高用户价值。前者偏向成本一侧，后者偏向需求一侧。大厂采用专门化设备降低成本，即使顾客彼此毫无联系，也可能有规模经济。

反过来，即使运营成本按用户数等比例增加，通信服务仍可能因为联系人更多而具有网络效应。产品也可能同时拥有两者。要判断一家公司为何领先，应分别收集成本曲线、用户之间的价值联系和替代选择证据，不能只把“规模大”说三遍。

两边都要有人，补贴就不只看这一边

双边市场 (two-sided market) 是平台连接相互影响的两组参与者，且对两侧怎样分配收费会影响参与与交易的情形。交易市场的商家与买家、内容市场的读者与广告主，都可以用作假想例子；关键是跨侧影响，不是网站里刚好有两个按钮。

如果空平台没有商家，买家不愿来；没有买家，商家也不愿承担入驻成本。这种启动难题可能让平台选择先降低某一侧的加入成本，等其参与提高了另一侧的价值，再从另一侧获得收入。要看整个交易体系，而不是把每个用户的账孤立相加。

交叉补贴 (cross-subsidy) 指用一处业务或一侧收入支持另一处的低价。在教学假设里，平台服务一个买家本期花 3 元，向买家收 0 元，却因增加该买家而多获得商家一侧净收入 5 元；若没有其他影响，整体新增净收益为 2 元。买家一侧亏 3 元不等于整笔业务亏 3 元。

这只是机制，不是任何平台的真实成本。如果初期两侧都在补贴，眼下的缺口可能来自投资资金，而不是已经赚到的交叉收入。平台赌的是未来交易、留存与收费能力；若用户只在有券时来、撤券就走，未来收入未必能填上早期支出。

补贴谁也没有固定答案。更容易被吸引的一侧、能给另一侧创造较大价值的一侧，可能得到低价；但成本、替代平台、交易质量和两侧的反应都重要。向一侧多收一元导致其流失，可能连带伤害另一侧收入，不能只用单边“加价乘数量”估算收益。

价格低，并不自动证明有害；价格高，也不自动合理

早期低价可以解决参与协调问题，也可能只是短期促销。是否涉及排除竞争，需要按上一课的框架看行为、替代与后果，不能仅因为低于某一侧成本就作结论。后来收费也要区分服务成本、早期投入回收与市场力量，不能用“曾经亏过”解释任意收费。

从小优势到大优势，中间需要足够强的反馈

临界规模 (critical mass) 指在给定环境中，足以支持继续参与或增长的用户基础。在竞争网络中，它可能表现为跨过某个份额阈值后，正向反馈会放大优势。实际阈值取决于价格、质量、用户组成与连接方式，不是一个放之四海皆准的人数。

倾倒 (tipping) 指微小领先通过反馈扩大，市场明显集中到一方的过程。为把这个机制单独展示，下面只模拟两平台的一类用户，不模拟商家侧、价格战或利润。它是网络效应玩具模型，不是完整的外卖平台预测器。

把 A 的用户份额记为 s，B 为 1 − s。平台的其他吸引力对称，参与者对产品仍有不同偏好。网络越强，选择倾向越受当前份额差影响；每轮只向新的选择倾向调整一半，避免把全体用户瞬间搬走。

选择 A 的倾向 L(s) = 1 / (1 + exp[−β(2s − 1)])

这是平滑的 logit 规则：A 越受欢迎，倾向 A 的比例越高，但有限强度下仍有人偏好另一家。β 是教学设定的无量纲网络强度，不是统计估计。

下一轮份额 s′ = 0.5s + 0.5L(s)

新份额是旧份额与选择倾向的平均，因此始终在 0 与 1 之间。每次从滑块给出的初始份额重新算 40 轮，没有随机噪声；相同参数必定得到相同轨迹。这里的一“轮”不是一天或一年。

五个实验，比一条“赢家通吃”口号更准确

  1. β = 0、A 初始 55%。网络因素不起作用，两家基础吸引力对称，旧优势逐渐淡化。不是 A 被惩罚，而是新的选择倾向一直为一半。
  2. β = 1、A 初始 55%。网络仍有正反馈，但还不足以克服偏好多样性带来的分散，份额趋向中间。“有网络效应”不等于“一定倾倒”。
  3. β = 3、A 初始 55%。小领先会扩展，A 接近较高的稳定份额，B 并不严格消失。把初始改为 45%，结局镜像反转：模型没有偏爱 A 这个名字。
  4. β = 6、A 初始精确 50%。两者仍各占一半，不会无故偏离。但改为 51% 或 49%，就会看到不同方向的放大。强反馈下的对称状态是不稳定的，不代表程序应替你加一次随机摇摆。
  5. β = 2、A 初始 55%。这是边界情形，向中间移动很慢。只画 40 轮不能把终点当成最终均衡，更不能把“暂时仍领先”当成已经锁定市场。

本规则在 50% 附近的偏差倍率为 0.5 + β/4：小于 1 时小偏差被缩小，大于 1 时被放大。β = 2 时倍率恰为 1，仍要看更细的非线性变化，不能用“线性倍率等于 1”推断任何起点都不动。读数让你核对临界条件，不要求背推导。

强网络时，50% 两侧分别朝两个偏向性的稳定状态移动。接近一半的初始份额可能先变化缓慢，之后才明显分开；40 轮内优势扩大多少取决于参数。实际市场可能有第三家、差异化质量与新进入者，甚至用户可以同时用两家，这些都可能打断图里的反馈链。

复制便宜，不代表平台没有总成本

零边际成本 (zero marginal cost) 是指在所讨论的范围内，再提供一单位产品几乎不新增成本。一个已经写好的假想数字文件，新增复制成本可以很低；研发、维护、安全、客服、内容生产和设备投入，却不会因此消失。若扩大用户触发容量升级，新增成本也可能跳升。

尤其不要把软件复制类比直接搬到一整单外卖。即使下单界面几乎可免费复制，做饭、配送、退款处理和客服仍可能随订单增加。平台手续费包含哪些服务、谁承担哪些成本，需要看合约，不能把整个交易链都当成一个数字文件。

如果固定投入很高而复制成本低，持续按接近零的单价出售，未必能覆盖总成本。订阅、广告、两部收费或另一侧收费，可以是筹资方式；但“需要覆盖成本”不决定唯一合理价格，更不免除对市场力量与分配的分析。低 MC 与高价格可以并存，高价也可能包含超过必要回收的加成。

用户为什么不立刻换平台

转换成本 (switching cost) 是从现有服务换到另一服务所需承担的额外代价，例如学习新界面、迁移数据、重新建立交易信誉或让合作伙伴一起迁移。它不是只指注销费，也不一定来自故意设置的障碍。

锁定 (lock-in) 指即使存在有吸引力的替代方案，转换成本与既有关系仍使用户难以离开。网络效应与锁定可以互相加强：你不仅要搬自己的资料，还要协调朋友或客户一起搬。新平台功能稍好，不代表净收益足以抵消迁移代价。

但留下来不一定证明被锁定。用户可能真心更喜欢现有服务，或另一个平台更差。要识别转换成本，可以问：在不丢失资料、信誉和联系人时，选择是否改变？不能把所有留存都归因于操纵，也不能因用户还能点“退出”就认定迁移没有障碍。

哪些机制可能抑制倾倒

多归属 (multihoming) 指用户或商家同时使用多个平台。若不必放弃旧平台就能试用新平台，小平台无需一次性搬走所有关系，进入障碍可能降低。多归属仍会花精力、设备与管理成本，是否容易，要分别看买家与卖家两侧。

互联互通 (interoperability) 让不同服务之间能够连接或交换兼容信息，可以削弱“为了联系某人必须加入同一家”的压力。数据可携带也能降低迁移代价。但实现这些安排需要考虑安全、隐私、滥用防护与技术责任，不是加一条开放规则就没有任何成本。

偏好多样性、地方化需求和容量拥挤也可能给多家平台留下空间。图中故意固定这些条件，展示单一反馈；现实分析应主动寻找抵消反馈的因素。市场集中有时带来更好的匹配，同时也可能增强收费能力，效率收益与分配后果应一起报告。

三个常见误解

“用户更多就是规模经济，有网络效应就必然只剩一家。”

成本下降与用户价值提高是两条机制。弱反馈、偏好多样性、多归属与互联都可能支持共存。强反馈也需要起点、差异或扰动，不能从对称状态凭空宣布赢家。

“边际成本接近零，平台的一切服务就应永远免费。”

低复制成本不消除固定投入，也不代表配送等服务没有可变成本。如何覆盖总成本与收费是否利用市场力量，是必须分别回答的问题。

“先补贴再收费一定是骗局；用户没走就说明没有损失。”

补贴可能解决双边启动问题，也可能无法收回投入。后续收费要看成本与竞争；留存可能来自真实质量，也可能来自转换成本，不能单凭留存判断用户福利。

回到新闻

  1. 为什么先补贴一方？更多用户可能提高商家入驻价值，更多商家又吸引用户。补贴可以启动跨侧反馈，另一侧或未来收入可能支持它；若两侧都亏损，则还需要资金。是否值得要比较完整新增账，不能只看被补贴一侧，也不能把未来回收当保证。
  2. 早期领先是否注定胜出？不一定。玩具模型里，弱网络使份额趋中，强网络放大非零差距，精确对称则保持对称；现实还受质量、价格、多归属、互联与进入影响。要核查用户之间的价值联系，不是把初期注册量直接当作永久赢家证明。
  3. 抽成与不退出怎么解释？软件复制便宜不代表做饭、配送、维护和固定投入为零，抽成可能覆盖服务或投入，也可能包含市场力量加成。用户留下可能因为服务更好，也可能因资料、信誉与关系难迁移。应查成本口径、收费服务、替代选择及退出代价，不能凭先补贴后收费这一条时间线作终局判断。

本模块把企业的成本账、定价能力、对手反应与用户反馈连在了一起。下一次分析平台新闻，先问它改变的是哪一本账，再说明模型没有包括什么；不要让一个漂亮的份额曲线替代真实证据。
