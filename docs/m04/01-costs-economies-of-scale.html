成本：固定、可变、边际与规模经济

Fixed, variable and marginal costs, and economies of scale

建厂很贵，不代表多做一件也很贵；多做一件便宜，也不保证整座工厂能赚钱。把成本拆成不同的问题，才能判断扩产、接单和建厂究竟是在改善哪一本账。

前置：边际思维与激励、剩余与市场效率。本课把“下一步的代价”放进企业的完整成本表。

从一条新闻开始

企业、金额与说法都是虚构设定，不是对任何芯片项目的报道。先假设新厂能生产质量相同的产品，也暂不考虑需求预测是否可信。把“总支出很大”与“每件平均支出很低”同时成立的原因找出来。

  1. 建厂花费巨大，为什么仍可能让每片产品更便宜？
  2. 厂房已建好后，是否应该接下一笔低于平均成本的订单？
  3. 是否只要不断扩大工厂，成本就会一直下降？

同一笔支出，先问时间与决策

固定成本 (fixed cost, F) 是在给定时期和产能范围内，不随产量变化的成本。假设本周租金已经确定，生产零件或少生产几件都要付这笔钱，这周的租金就是固定成本。“固定”不是说金额永远不变，而是说它不随本次比较的产量变。

可变成本 (variable cost, VC) 随产量而变，例如假设中的材料、生产用电与额外工时。每件都需要材料，不代表每件材料加服务的成本相同；加班、拥挤和设备磨损可以使后面的单位更贵。

总成本 TC = F + VC

总成本包含为生产动用的全部相关资源。这是经济成本账，原则上也包括自有厂房和资金放弃其他用途的机会成本，不只包括向外付款的发票。下面模型将这些成本都折为同一货币单位，避免把“没有付款”误读为“没有代价”。

固定不等于沉没

沉没成本 (sunk cost) 是此刻已经无法收回的支出。固定看的是“是否随产量变化”，沉没看的是“现在能否收回”，两条分类轴不同。一台本周不随产量收费、但可以转售的机器，有固定成本性质，却不代表其全部价值都已经沉没。

反过来，昨天为一笔订单买了无法退换、也无法转用的专用材料，那笔支出当时随订单而变，今天却可能已经沉没。讨论是否继续时，要数未来可避免的支出和放弃的转售价值，而不是只看账簿把它记在哪一栏。

建设前，厂房方案可以取消，预期收入必须覆盖建厂、运营与资金占用等全部相关成本。建设后，短期是否接单则要看订单新增的收入与可避免成本。不能用“钱已经花了”替新项目辩护，也不能把全部建厂费再重复算进每一次临时订单。

类比

几个人合租一辆车出游。租车费确定后，多坐一个人不再增加租金，油费与其他服务却可能增加。把租金分给更多乘客，会降低每人的平均账单；但这不表示车能无限塞人。超出容量要再租一辆车，原来的固定条件就变了。

平均问整本账，边际问下一步

平均成本 (average cost, AC) 是总成本除以产量，也称平均总成本。它回答“已经生产的这些单位，平均分担多少成本”。平均可变成本 (average variable cost, AVC) 只把可变成本分给产量；平均固定成本 (average fixed cost, AFC) 则是 F/Q。

Q > 0 时：AC = TC/Q = F/Q + AVC

同样一笔固定成本，产量越多，每件分到的越少。AC 与 AVC 的竖直距离就是 F/Q，不是额外的一种成本。Q = 0 时没有任何件可供平均，三个平均数都未定义；不能为了画出一条完整线，偷偷把它们设成零。

边际成本 (marginal cost, MC) 是产量增加一点带来的新增总成本。在可细分的光滑模型里，它是总成本曲线的斜率。固定成本不随这一步改变，因此增加 F 会抬高 AC，却不会改变 MC 或 AVC。

若货物只能整件增加，应直接比较 TC(Q+1) − TC(Q)。图中 MC 是某一点的瞬时增量，不是整件差额。它与平均数在单位上都是“元/件”，含义却不同：一个回顾全部产量，一个询问下一点。

为何 MC 穿过 AC 的最低点

想象当前平均每件花 50 元。下一小批单位的成本低于 50，加入后会拉低平均；高于 50，就会抬高平均。只要曲线连续、可微，且最低点在正产量的内部，平均数从下降转为上升的位置就满足 MC = AC。

这不是要求每家工厂必有漂亮的 U 形。若平均成本一直下降，或可行产量有边界，最低值可能在边界；若要整座新建产线，成本也可能跳跃。相交于内点最低值，是有形状与可细分条件的结论。本图选择一个能明确看到这种关系的模型。

全部数字为教学示意，TC = F + aQ + Q²，VC = aQ + Q²，MC = a + 2Q；Q 的单位为件/周，系数的单位与之配套。对 Q > 0，AVC = a + Q，AC = F/Q + a + Q。纵轴随参数与观察点调整；AC 在接近零产量时超出图框的部分裁去，平均曲线不连接到 Q = 0。零产量的 MC 表示从右侧开始增加产量的边际代价。未建模需求、产能阶跃或长期换厂。

用三步实验读懂三条线

  1. 保持 F = 100、a = 12，Q = 10 时：VC = 220，TC = 320，AVC = 22，AC = MC = 32。AC 与 AVC 相差 10，正是每件分担的固定成本。
  2. 只把 F 提到 360，仍看 Q = 10。TC 变成 580，AC 变成 58，MC 仍为 32，AVC 仍为 22。新增固定支出没有让“下一件”更贵；最低 AC 的产量却右移，因为要更多产量才能摊薄它。
  3. 把 F 改回 100，再把 a 从 12 提到 24。每件的基础支出增加 12，AC、AVC、MC 都上移 12；最低点的产量不变。先预测，再拖动核对，而不是只看线的颜色。

本模型的最低 AC 产量是 √F。若 F = 100，它为 10；若 F = 360，约为 18.97。允许连续产量时才能精确达到后者。这里 AVC 一直上升，而 AC 先降后升：前半段摊薄固定成本的效果更强，后半段可变成本上升的效果更强。

AC 最低不是“企业应该生产这里”的完整答案。若顾客只愿买很少，最低平均成本也不能替它创造订单；若售价很高，超过这个数量仍可能有利可图。产量决策还要把新增收入与 MC 比较，下一课再把需求与成本接起来。

短期多开机器，不等于长期扩大规模

短期 (short run) 指至少某些生产投入还来不及调整的时期；长期 (long run) 指相关投入都可以选择的时期。它们不是统一的几个月或几年，而取决于要调整的是排班、设备还是整座工厂。

规模经济 (economies of scale) 指长期选择合适投入与厂型时，扩大产出规模使每单位成本下降。例如在一个假想加工项目中，更大的需求允许采用专门化设备与分工；原来小规模无法合理采用的工艺，现在可能降低单位资源消耗。

这与图上“同一厂房里提高 Q、摊薄 F”有联系，却不是同一个判断。图中的 F 固定，只有同一短期成本曲线；要证明长期规模经济，应比较多个可行厂型在不同规模下的最低单位成本。只看到旧厂利用率上升，证据还不够。

规模不经济 (diseconomies of scale) 则是长期扩大规模反而提高平均成本。例如假想团队扩大后，多层审批、跨厂协调和信息传递消耗更多资源。如果产出扩大多少，总成本就恰好同比扩大，长期平均成本不变，也不属于这两种情况。

便宜的来源，要逐项拆开

大公司的采购单价更低，可能是更高效率，也可能只是向供应商重新分配了收益；“付的钱少”不必然说明社会动用的资源少。累计经验带来的熟练，也不等于当前规模本身的效果。技术改进、投入品降价和产品质量变化，都能让平均成本下降。

因此，读到“产量翻倍、单位成本下降”，至少追问：是否同一质量？是否同一时期与投入价格？是否换了设备？是否把研发、维护与资金成本漏了？这不是否定规模优势，而是要求把机制与证据一一对应。

接单与退出，是不同范围的比较

假设厂房成本本周无法避免，售价低于 AC，但新增订单收入高于全部新增可避免成本，接单可能减少亏损。若整周是否开工也是可选的，还要比较整周收入能否覆盖全部可避免运营成本，不能只看最后一个单位。

长期则不能永远靠“至少补贴了一点固定成本”维持一个不值得重建的项目。到租约续签、机器更新时，那些原先固定的承诺重新成为可以避免的选择。这里沿用沉没成本分析：换一个决策时点，就重画一次相关成本边界。

三个常见误解

“固定成本涨了，MC 就一定涨。”

在相同技术与产能范围内，纯粹改变 F 不改变新增一件所需资源。AC 上升，但 MC 与 AVC 不变。若同时换设备，则已不只是 F 的变化。

“已经花在厂房上的钱，肯定全部沉没。”

看能否退租、转售或转用。可回收价值是当前选择的机会成本；固定与沉没不能互换。未来的新厂建设费更不能因旧厂已建而被忽略。

“AC 下降证明规模经济，所以越大越好。”

同一短期工厂摊薄 F，不足以证明长期规模经济。规模扩大可能带来协调成本；AC 最低也不是需求约束下必然最赚钱的产量。

自测

每道题先说清正在改变哪个成本、比较哪个决策。所有数值为教学假设。

闪卡

先回忆定义，再加一句它与相近术语的区别。

回到新闻

  1. 为什么昂贵的新厂仍可能降低每片成本？订单量足够大，可以分摊固定投入；若允许选择新工艺，也可能产生长期规模经济。但建设前必须用预期销量、全部成本和替代方案比较，不能仅凭单片制造成本低就宣布项目值得建。
  2. 低于平均成本的订单能不能接？厂已建且本期固定支出不可避免时，比较这笔订单的新增收入与全部新增成本，包括放弃高价订单、加班和交付风险。收入超过这些代价可能减少亏损，不保证整厂盈利，也不保证该低价适合长期维持。
  3. 是不是越扩越便宜？同一产能内，拥挤与加班可能使 MC 上升；换成更大组织后，也可能出现规模不经济。需要不同厂型、利用率和质量一致的成本证据，不能把 AC 的下降段无限外推。

能解释“为什么可能”，不等于已经判断新闻中的投资会成功。真正的项目还要核查订单是否稳定、技术是否兑现、资金是否够用。本课提供的是分账方式，不是投资建议。
