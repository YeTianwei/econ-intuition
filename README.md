# 可以拖动的经济学 econ-intuition

一套中文的交互式经济学原理课程。每一课从一条新闻出发，用直觉和类比讲清一个原理，再配一个可以拖动参数的图，让你亲眼看到价格、数量和福利如何变化。

在线阅读：https://yetianwei.github.io/econ-intuition/

## 课程结构

| 部分 | 模块 |
|---|---|
| 微观 | 1 经济学思维 · 2 供需与弹性 · 3 市场效率与干预 · 4 企业与市场结构 · 5 博弈与策略 · 6 信息与行为 · 7 劳动与分配 |
| 宏观 | 8 衡量经济 · 9 长期增长 · 10 货币与通胀 · 11 经济周期与稳定政策 · 12 金融市场 · 13 开放经济 |
| 应用 | 14 案例专题 |

完整大纲见 [CURRICULUM.md](CURRICULUM.md)。

## 每一课包含

- 一条新闻作为开场
- 核心原理的直觉解释和类比
- 0~1 个交互图
- 常见误解
- 5 道自测题和一组闪卡
- 用学到的原理回头拆解开场的新闻

## 本地预览

```bash
cd docs
python3 -m http.server 8000
# 打开 http://localhost:8000
```

纯静态 HTML，无需构建。

## 说明

- 交互图中的数字是教学用的示意值，不代表真实市场数据。
- 标注为「示例标题」的新闻是为教学拟写的，不是真实报道；引用真实事件的地方都附有来源。
- 内容由作者与 AI 协作编写。如发现错误，欢迎提 issue。
